Supplier Price & Availability Monitor

A procurement bot that checks 7 retail suppliers every morning, compares live prices against the last known price, and raises alerts on ≥5% moves or stock changes — replacing a 60–90 minute manual routine. Watch a replay of a verified run below.

    Proof from the real run

    When a supplier page hides its stock status, the bot falls back to an add-to-cart heuristic: if the item can be carted, it’s in stock. This capture from the actual run shows the heuristic firing on Adorama — and the $2,909.00 it saw is exactly the reference price recorded in the workflow.

    How the bot works

    1 · ReadLoads suppliers, per-row thresholds and last known prices from Excel.Read_Input.xaml
    2 · ScrapeOpens Chrome per supplier; site-specific selectors extract price and availability, with reference-data fallback if a selector breaks.Process_Supplier.xaml
    3 · CompareComputes (new − old) / old, checks the threshold and stock changes, applies the PDD’s exception rules.Main.xaml
    4 · WriteAppends every check to the audit log, breaches to the Alert Sheet, and refreshes the supplier list.Write_Output.xaml
    Built in UiPath Studio against a formal Process Design Document · source, PDD and iteration history: github.com/ezieshie-stack/UiPath-Automation-Project
